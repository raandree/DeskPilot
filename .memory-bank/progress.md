## Decision log

- **2026-06-08 — PowerShell Host Server over Electron/Node.** In-process Engine
  integration, zero extra runtime, fit with the PowerShell ecosystem.
- **2026-06-08 — `TcpListener` + hand-rolled HTTP over `HttpListener`.** Avoids
  Windows URL-ACL/admin friction; fully cross-platform on loopback.
- **2026-06-08 — SSE over WebSockets.** One-directional token streaming is
  simpler and more robust.
- **2026-06-08 — Conversation isolation via `-History`.** Avoids the Engine's
  module-scoped running chat bleeding across Conversations.
- **2026-06-08 — Build-free static SPA.** No toolchain for end users.
- **2026-06-08 — In-house XSS-safe Markdown renderer.** Escape-first, safe
  subset; no third-party script to vendor or audit.
